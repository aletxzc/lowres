# Models use invented names, never trademarks

Models get generic, invented names (Handheld 3D, CCD Digicam, Disposable) and may be described as inspired by a kind of device, but never use real product names, logos or copied interfaces (no "3DS", "Polaroid", "Game Boy"). Rights holders can get a public repository taken down, which would remove the whole project, and some console makers have a long record of doing so on GitHub. Please don't rename a Model after the real device it evokes.
